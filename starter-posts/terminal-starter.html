The terminal is a text-based way to ask your computer to do things. It can look intimidating at first, but you only need a few small commands to navigate folders and inspect files. These examples are intentionally basic and avoid administrator privileges or destructive cleanup.

Open the terminal app included with your Linux desktop. Commands are entered at the prompt; press Enter to run one. For these examples, keep an eye on the folder you are working in.

1. See your current folder with pwd

pwd

pwd prints the current working directory. It is a useful first check before you create, copy, or move anything.

2. List files with ls

ls
ls -lah

The first form lists names in the current folder. The options in ls -lah show more details, include hidden entries, and make file sizes easier to read. Options can vary across systems, so use ls --help if you want to see the details for your version.

3. Move between folders with cd

cd Documents
cd ..
cd ~

cd Documents enters a folder named Documents in the current location; cd .. moves up one level; and cd ~ returns to your home folder. Use pwd afterward if you are unsure where you landed.

4. Create a folder with mkdir

mkdir linux-notes

This creates a folder called linux-notes in your current location. If a folder with that name already exists, the command reports that rather than replacing it.

5. Copy a file with cp

cp notes.txt notes-backup.txt

This makes a second file named notes-backup.txt alongside the original. Check the destination and filenames before running a copy command, especially when copying folders or using wildcard characters.

6. Rename or move with mv

mv draft.txt first-draft.txt

Here, mv renames a file. It can also move a file to another folder. Because it changes where the original file is, check both names carefully before pressing Enter.

7. Find text with grep

grep -n "TODO" notes.txt

This searches notes.txt for the text TODO and shows matching line numbers. If there are no matches, the command simply returns no matching lines.

Two habits that make the terminal friendlier

  • Use man command (for example, man cp) or command --help to read about a command before trying unfamiliar options.
  • Be cautious with commands copied from the internet. Understand what they do, particularly if they include sudo, administrator access, deletion, disk tools, or a command piped straight into a shell.

Try one command at a time in a folder containing practice files. The terminal becomes less mysterious as each short instruction starts to make sense.
