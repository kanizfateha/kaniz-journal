The terminal looks mysterious the first time you open it. It is just a way to give your computer short, precise instructions by typing commands. You do not need to memorize dozens of them or use the terminal for everything. These four basics help you understand where you are and move around safely.

For this guide, the examples are for looking around—not deleting files or changing system settings. You can try them in your usual terminal app. The prompt symbol ($) is shown for context; you do not type it.

1. Ask, “Where am I?” with pwd

pwd stands for “print working directory.” It shows the full path to the folder the terminal is currently using.

$ pwd
/home/kaniz

Your result will be different. That is okay: it tells you the current location, not where every file on your computer lives.

2. See what is in a folder with ls

ls lists the visible files and folders at your current location.

$ ls
Desktop  Documents  Downloads  Pictures

Want details such as hidden files, file sizes, and modification dates? Try ls -la. In that command, -l asks for a longer listing and -a includes hidden entries whose names start with a dot.

3. Change folders with cd

cd means “change directory.” Give it the name of a folder you can see:

$ cd Documents
$ pwd
/home/kaniz/Documents

To move up one folder, use cd ... To return to your home folder, use cd ~. Linux distinguishes uppercase from lowercase, so Documents and documents may not be the same name.

4. Read the help before guessing

Many commands have a built-in help option. man ls, for example, opens the manual page for ls; press q to leave it. For a shorter summary, ls --help prints the available options in many common Linux tools.

Three little habits that make the terminal friendlier

  • Tab-complete names. Type the first few letters of a file or folder name, then press Tab. The shell may complete it, or show matching choices.
  • Use the up-arrow. It recalls a previous command so you can review or edit it instead of typing it again.
  • Read a command before pressing Enter. A command can do exactly what its options ask. If you do not understand a line you found online, pause and look up the program and its options first.

These commands only inspect or navigate your files. For a first practice session, try pwd, then ls, then cd into a folder you recognize. If a command behaves differently on your distribution, check its manual or your distribution’s documentation—Linux has many tools, and their options can vary.
